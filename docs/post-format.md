# ブログ記事ファイルの書式

AI（ChatGPT / Gemini）も人も、この書式で記事ファイルを1つ作れば投稿できます。

## ファイルの置き場所と名前

```
content/blog/
├── 2026-11-08-coin-laundry-checklist.md   ← 記事本文（1記事 = 1ファイル）
└── images/
    ├── 20261108-coin-laundry-cover.jpg    ← アイキャッチ画像
    └── 20261108-coin-laundry-1.jpg        ← 本文中の画像
```

- 記事ファイル名: `YYYY-MM-DD-英小文字のスラッグ.md`
  - スラッグは記事URLになります（例: `/blog/coin-laundry-checklist`）
  - 使える文字: 半角英小文字・数字・ハイフンのみ
- 画像ファイル名: `YYYYMMDD-スラッグ-番号.jpg`（`cover` はアイキャッチ）
  - 形式: jpg / png / webp / gif
  - 1枚 2MB 以下（推奨: 横幅 1600px 程度に縮小）

## 記事ファイルの中身

```markdown
---
title: 記事タイトル（全角32文字程度まで）
date: 2026-11-08
category: 開業ノウハウ
description: 検索結果やSNSに表示される要約文。120文字程度まで（最大160文字）。
cover: images/20261108-coin-laundry-cover.jpg
tags: コインランドリー, 開業, 土地活用
---

導入文。

## 見出し

本文。

![画像の説明（キャプションとして表示）](images/20261108-coin-laundry-1.jpg)
```

### 記事情報（`---` で囲んだ部分）

| 項目 | 必須 | 内容 |
|---|---|---|
| title | ○ | 記事タイトル |
| date | ○ | 公開日。`YYYY-MM-DD` |
| category | ○ | `お知らせ` / `導入事例` / `コラム` / `開業ノウハウ` のいずれか（`site.json` で変更可） |
| description | ○ | 要約文。160文字以内 |
| cover | ○ | アイキャッチ画像。`images/ファイル名` |
| tags |  | カンマ区切り |
| slug |  | URLを指定したい場合のみ。省略時はファイル名から自動 |
| draft |  | `true` にすると公開しない（下書き） |

### 本文で使える書き方

| 書き方 | 表示 |
|---|---|
| `## 見出し` | 大見出し |
| `### 見出し` | 小見出し |
| 空行で区切った文章 | 段落 |
| `- 項目` | 箇条書き |
| `1. 項目` | 番号付きリスト |
| `**強調**` | 太字 |
| `[文字](https://...)` | リンク（外部リンクは新しいタブで開く） |
| `[文字](../contact.html)` | サイト内リンク |
| `![説明](images/xxx.jpg)` | 画像（1行に単独で書く） |
| `> 文章` | 引用・補足 |

HTMLタグは使えません（書いても文字として表示されます）。

## 公開前チェック（自動）

`python3 build.py --check` または Cloudflare のビルド時に、次をチェックします。
1つでも問題があれば **公開されません**（今の公開内容はそのまま残ります）。

- 必須項目がそろっているか
- 日付の形式、カテゴリが登録済みか
- 画像ファイルが存在するか、2MB以下か
- スラッグの重複がないか
